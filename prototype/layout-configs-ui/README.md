# PROTOTYPE — Layout Configs UI

Throwaway HTML mock of the **Layouts** tab + editor shapes for [Rough Layout Configs tab and editor to react to](https://github.com/adamk33n3r/GoBorderless/issues/23).

Not Fyne. Not production. Sample data only.

## Run

```sh
start prototype/layout-configs-ui/index.html
# or open the file in a browser
```

Switch variants with the bottom bar or `?variant=A|B|C` (also ← / → keys).

| Key | Shape |
| --- | --- |
| A | Apps-mirror list + modal editor |
| B | Master–detail split (no modal) |
| C | Chip strip + dual-pane editor |
